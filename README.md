# Gloamdeep

A lantern-lit, turn-based dungeon survival game for phones and browsers.
You carry a lantern down through dark places, and every step burns oil.

**Status:** pre-production. There is no playable game yet. The art
direction comes from `reference/style-study-1.html`. Open it in any
browser to walk around the first test room, or play it online:
https://avatar-coco-love.github.io/gloamdeep/reference/style-study-1.html

Everything is drawn and synthesized in code: no image, sound or font files.
