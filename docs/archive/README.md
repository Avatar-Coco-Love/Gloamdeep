grep. Never read them whole. The 8 KB cap doesn't apply here.

- `DECISIONS-SUPERSEDED.md`: superseded decisions, moved from
  `DECISIONS.md` once it passes 12 KB.
- `CHANGELOG-PREPRODUCTION.md`: the 0.0.x changelog entries, moved
  unchanged from `CHANGELOG.md` when it passed 8 KB.
- `DECISIONS-PREPRODUCTION.md`: D-001 to D-038, moved unchanged from
  `DECISIONS.md` at step 8 (D-041). Still in force.
